# SumaiBoard（すまいボード）

住宅相談ビジネスの業務フローを体験できる非公式プロトタイプです。顧客相談、複数住宅会社への紹介と並行商談、契約、実際着工の確認、報酬確定・請求までを操作できます。デモデータはすべて架空です。

## 技術構成

- FastAPI + React (Vite) を単一の `app` コンテナで配信
- MySQL 8 (`utf8mb4`) を別コンテナで稼働し、Compose 内部ネットワークのみで接続
- named volume によるデータ永続化、起動時の自動テーブル作成とデモデータ投入
- 日本語を既定言語として中文へ切替可能

## 起動

Docker と Docker Compose がある環境で、リポジトリのルートから `.env` を用意して起動します。

```sh
cp .env.example .env
# .env の DB_PASSWORD と MYSQL_ROOT_PASSWORD を別々の長いランダム値に変更
docker compose up -d --build
```

アプリは `127.0.0.1:8000` のみに公開されます。VPS での宝塔リバースプロキシ、Let's Encrypt、再起動後の確認手順は [DEPLOY.md](DEPLOY.md) を参照してください。

## デモ操作

1. `.env` の `DEMO_MODE=true` で起動し、ログイン画面から顧問・店長・本社／経理・社長の演示アカウントを選びます。画面右上の言語切替で日本語と中文を切り替えられます。
2. 顧問の Dashboard で期限超過のフォローを開き、Household 詳細から Activity と次回行動を登録します。未完了 Task が完了すると、期限超過数に反映されます。
3. Households で `HH-D020` を開くと、住宅会社 3 社への並行紹介と個別の商談状態を確認できます。紹介の追加やステージ更新は Introductions から操作します。
4. Revenue で着工確認待ち案件の予定日・実着工日を確認し、証跡を入力して着工確認します。FeeEntitlement は適用 FeeRule のバージョンと計算根拠を保持して生成されます。
5. 本社／経理で報酬を承認し、請求データ生成済み・請求済・入金済みへ進められます。争議中の金額は凍結され、請求額・確定売上に含まれません。
6. Management では期間別トレンド、5 つの店舗運営指標、期限リマインダー、同条件店舗比較、流入経路・相談月別 Cohort、住宅会社別報酬処理品質を確認できます。店舗運営指標は総合点や順位に集約しません。
7. Settings の「デモデータをリセット」で、店舗A〜L・住宅会社A〜Lと HH-D001〜HH-D060 の初期データを復元できます。

## 月次締め

「設定」の月次締めパネルで対象月の集計スナップショットを準備し、別の社長／管理者ロールで締めを確定します。締め後は設定された業務データがロックされ、変更が必要な場合は理由付きの再オープン申請と別担当者の承認が必要です。スナップショットはバージョンと SHA-256 で保持します。この機能は月次集計と編集ロックのみを行い、請求書発行や入金消込は行いません。

顧客データの修正は申請と別担当者の承認を経て監査ログへ記録されます。第三者提供は有効な同意のある L2/L3 に限定して記録し、L1 の共有や実データの送信は行いません。運用状態パネルでは監査チェーン、Outbox、期限切れ出力などを確認できます。メール配送は未接続のため、メール通知を有効にした場合は対応タスクへフォールバックします。

「請求済・未入金」は演示用 FeeEntitlement 状態で表示します。製品版では会計システムから状態を連携する想定で、SumaiBoard は請求書を発行せず、入金消込もしません。

演示データはすべて架空です。店舗名は店舗A〜L、住宅会社名は住宅会社A〜L、顧客名は姓と英字のサンプル名を使用します。`DEMO_MODE=false` の場合は通常の社員番号・パスワード認証を使用し、パスワードなしの演示ロール切替は無効になります。

Settings のデータ入出力から、権限範囲内の一覧を CSV または PDF レポートとして作成・ダウンロードできます。PDF は固定テンプレートを WeasyPrint で生成し、日本語・中文フォントをアプリイメージに同梱します。出力は有効期限付きで、作成・ダウンロードを監査ログに記録します。PDF は一覧レポートであり、請求書発行や入金消込には使用しません。

## 開発

API: FastAPI (`backend/main.py`)、UI: React + Vite (`frontend/`)、DB 接続先は環境変数 `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` で設定します。ローカル開発でも MySQL 8 が必要です。

```sh
cd frontend
npm install
npm run dev
```

別ターミナルで API を起動します。Compose の `.env` と同じ MySQL 接続環境変数を設定してください。

```sh
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```
